# 零次方 · 合肥具身智能展厅

分享链接：https://zoiewong-hub.github.io/robot/hefei-showroom/?v=20261030-7

本版修正一脑多形和两套悬挂棒的朝向，面向环廊观众。三设备展台前移至弧墙内侧，独立查看设备一时不再被算法屏遮挡；导览 H1 停靠在工位侧方。

数据驾驶舱由人类采集员操作手持采集端，物体搬运与六套系统屏幕状态同步。入口导览 H1 继续保留。

设备一和二采用水平嵌入式动态桌面屏，显示动态背景、目标框及抓取状态，同时保留可移动的真实三维物体。设备一机器人侧左框是杂物栏，靠观众的右框是置物区；设备二后方为杂物栏，观众前端三个槽为按指令顺序排列的置物区。设备三的圆环传送带环绕中央双臂基座，四类开放料筐在传送带外侧，留有间隔；目标来自环线，连续动态识别和分类。三设备共用 T0 夹爪。参考苏度与梅卡曼德的展示原则，以原创流程动画呈现，不声称精确复刻现场展台。

工业长程改为靠楼梯侧浅色隔墙的车辆侧框与坡面桌面，工作区约 4.2 米宽、1.95 米深。取消占地较大的独立完整车架平台，机器人在前方沿墙移动，60 秒完成车内零部件、盖板、钣金件、车灯电池、车灯线束五步装配，装配物落在同一坡面上。

右下角默认约 130 像素高的轻量控制条，播放、前后站和 iPad/随机新一轮等快捷操作始终可用；点击“详情”展开设备选择、说明及高级控制。手机也采用相同逻辑。

比例继续按尺寸参考图每格 1 平方米校准，图像估计展厅约 41.5×31.2 米，中央圆区直径约 12 米；H1 约 1.6 米高，设备一和二桌宽约 1.70 米、高 0.80 米。尺寸不作为施工测量依据。保留白色弧形空间、航空机械臂与行星、面向观众的双足舞者、环墙背面荣誉生态、咖啡吧、小店、房间整理、前置仓通道和三个会议室。

操作：拖动旋转，滚轮缩放，右上目录选站；右下“播放演示”和上下站，iPad 可指定 1–3 件抓取物或拖动物品到目标家具。
