# 零次方 · 合肥具身智能展厅

分享链接：https://zoiewong-hub.github.io/robot/hefei-showroom/?v=20261102-8

2026-11-02 r8：15 个导览站、6 个互动展项。

零件展台向硬件区移动，避开数据驾驶舱。浅色背墙从一脑多形连续延伸到双套悬挂棒和工业长程区域。三块机器人决策 UI 屏沿弧墙贴合布置，与算法屏及相邻屏留出间距，动态更新目标、规划、执行和统计。保留两个动态桌面屏。

工业长程采用平整圆角桌面，机器人背墙、面对观众；桌面前端五个物料盒依次为线束盒、电池架、钣金件、盖板架、零部件盒。靠机器人侧预置支架模组和大灯总成。机器人从前端取件，在后端支架依次安装车内零部件、盖板、钣金件、车灯电池，最后连接大灯线束；连接确认后大灯亮起，重播会复位。五步连续装配共 60 秒。模型为展厅流程示意。

房间整理 iPad 支持把物品拖到茶几、沙发、置物架或收纳篮，放手后目标保留，并显示“待执行”；关闭再打开同样保留。点击“执行整理”后 H1 逐件搬运，完成后标记完成。三维实际物品在执行前保留原位置，目标位置和实际状态分开管理。支持修改未完成目标。

咖啡吧已从场景、导览路线、目录、标识和讲解中取消。保留中央双足舞者、航空机械臂与行星、环墙背面荣誉及生态合作、人类数据采集员、一脑多形共用 T0、两套随机落棒人机互动、小店、前置仓通道和三个会议室。

整体维持白色亮色弧形空间。按尺寸参考图每格 1 平方米校准，图像估计展厅约 41.5×31.2 米、中央圆区直径约 12 米；H1 约 1.6 米高，设备一和二桌宽约 1.70 米、高 0.80 米。尺寸不作为施工测量依据。

操作：拖动旋转，滚轮缩放，右上目录选站；右下轻量控制条播放演示、切换上下站。详情内选择设备视角；iPad 可指定 1–3 件抓取物，或拖动物品安排房间整理。
