# 零次方 · 合肥具身智能展厅

分享链接：https://zoiewong-hub.github.io/robot/hefei-showroom/

本次按建筑布局图重建外围轮廓、各房间与展位。东北为企业概况及历程；东侧依次为爆炸图、产品线、零件；东南六屏驾驶舱与算法模型；南侧三设备一脑多形及两套接棒；西侧工业长程、房间整理、小店；北侧解决方案区保留咖啡吧。前置仓、三个会议室、工作室、沙龙会客区及交通设施按图定位。仅使用最新参考图的尺寸：浅色格子 1 平方米，约 24.4 像素/米；换算展厅宽约 41.5 米、深约 31.2 米、中央圆区直径约 12 米。H1 身高保持约 1.6 米，三设备工作台缩至约 1.70 米宽、0.80 米高，工位屏约 1.59×0.86 米。尺寸为图像标定估计，不作为施工测量。

三台设备共用 T0 夹爪：单臂密集抓取 50 个 SKU；H1 接收 iPad 指定的 1–3 件困难物品；双臂在传送带连续分类到四类筐。房间 iPad 支持拖动物品到目标家具，发送任务后由 H1 整理；工业长程参考用户提供的 Figure 宝马工厂图，展示长约 3.72 米的缩比开放式汽车车身、黄色工装、五类物料架和连续五步装配：车内零部件、盖板、车身钣金、车灯电池、车灯线束；60 秒完成一轮流程动画。悬挂棒区设机器人和观众两套装置，随机落棒后接住，可点击“随机新一轮”。算法屏展示用户提供的 ZERITH V2 系统图，可放大查看；各显示屏贴合弧形墙面。

保留白色弧形空间、中央航空机械臂及行星装置、面向观众的双足人形舞者、环墙外侧荣誉与生态合作、入口西北通道及三个会议室。荣誉和合作资料采用分类展示位。

拖动旋转、滚轮缩放、右上目录选站；右下角播放演示、切换站点与打开 iPad 选择物品或指定房间整理位置。通过普通静态服务器即可运行，无需安装或后端。GitHub main 推送后由现有 Pages 工作流发布。
