# 零次方 · 合肥具身智能展厅

分享链接：https://zoiewong-hub.github.io/robot/hefei-showroom/

本次按建筑布局图重建外围轮廓、各房间与展位。入口东北侧新增宣传打卡点；东侧企业概况和发展历程分开；东南为产品陈列与核心零件；南侧为模型图介绍和六屏驾驶舱；西南为一脑多形与人机接棒；西侧为咖啡吧和房间整理；机器人小店在北侧。前置仓、三个会议室、工作室、沙龙会客区及交通设施按图定位。图中无尺寸，按相对比例建模。

一脑多形由三台设备演示左右框抓放、困难物自定义顺序抓取、左右臂螺栓螺母分拣。悬挂棒区设机器人和观众两套装置，随机落棒后接住，可点击“随机新一轮”。算法屏展示用户提供的 ZERITH V2 系统图，可放大查看；各显示屏贴合弧形墙面。

保留白色弧形空间、中央航空机械臂及行星装置、面向观众的双足人形舞者、环墙外侧荣誉与生态合作、入口西北通道及三个会议室。荣誉和合作资料采用分类展示位。

拖动旋转、滚轮缩放、右上目录选站；右下角播放演示、切换站点与设置抓取顺序。通过普通静态服务器即可运行，无需安装或后端。GitHub main 推送后由现有 Pages 工作流发布。
